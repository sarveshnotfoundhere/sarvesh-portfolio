# Sarvesh M — Portfolio

An immersive personal portfolio and resume website for Sarvesh M, focused on finance, business, leadership, creative work, and digital experiences.

## Planned Stack

- Next.js
- React
- Tailwind CSS
- Framer Motion
- Three.js / React Three Fiber
- Vercel

## Content Source

Resume and LinkedIn profile data supplied by the owner of this repository.

## Design Direction

Dark blue atmospheric gradient, animated grain, editorial typography, subtle 3D depth, and motion-led storytelling.
